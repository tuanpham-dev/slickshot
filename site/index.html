Region PrintScreen

Drag a rectangle anywhere, across monitor boundaries if you like. A pixel loupe follows the cursor while you aim, and the selection stays resizable from any edge before you commit.

Screen, monitor, window Shift/Ctrl+PrintScreen

The whole virtual desktop, one monitor picked by name and resolution, or a single window - each straight to the editor.

Repeat region

Re-shoot the exact rectangle you used last time. For capturing the same panel over and over while something changes inside it.

Pick color

Magnify any pixel on screen and lift its value - no capture, no editor, straight to the clipboard.

Measure

Drag a line between two points on screen and read the distance in pixels. For checking spacing against a design without pasting anything anywhere.

Translate / extract text Ctrl+Shift+PrintScreen

Drag over text in an image, a video, or an app that won't let you select it, and get it back as text - optionally translated. More below.

annotate

A real editor, not a doodle pad.

Fifteen tools with single-key shortcuts, full undo/redo, and a properties panel that follows whatever you have selected. Shapes stay editable after you draw them - move, restyle, or delete any of them at any point.

Spotlight

Dims everything outside the shapes you draw, to a darkness you choose. The fastest way to say “look here” without cropping away the context.

Numbered markers

Drop 1, 2, 3 as you walk through a flow. Delete one from the middle and the rest renumber themselves.

Backdrop

Pad the shot with a gradient or solid-colour background from a set of presets - for slides and release notes where a bare screenshot looks unfinished.

Pixelate & highlight

Mosaic over anything that shouldn't ship - tokens, addresses, customer names - and swipe a translucent highlighter over what should.

Crop and inspect

Trim to what matters, then zoom to 100% to check the pixels. The status bar tracks the cursor's position in image coordinates the whole time.

Insert an image

Drop a second image onto the canvas - a logo, a cursor, another capture - and move or resize it like any other shape.

extract

Text out of anything on screen.

Drag over a paused video, a screenshot someone pasted into chat, an error dialog that won't let you select its own message - and get the text back. QR codes in the same region are decoded in the same pass.

Native engines, on device

Recognition runs locally on every platform - nothing is uploaded to read your screen.

  • macOS - the built-in Vision framework
  • Windows - the built-in Windows.Media.Ocr engine
  • Linux - Tesseract, pulled in as a package dependency by the .deb and .rpm

Translation is opt-in

Turn it on in Settings and the result gets a second tab with your target language, plus a Listen button. Both send text to a Google endpoint, which is exactly why they stay off until you ask.

Three ways in

The editor's Extract text tool O, the main window's Translate/Extract mode, or slickshot ocr file.png from a terminal. Same engine behind all three.

export

Clipboard, disk, or a URL.

The export button remembers whichever of the four you used last and makes it the default, so the common case is one click or one chord.

Four ways out

Copy Ctrl+C · Save As Ctrl+Shift+S · Quick save to a fixed folder · Upload Ctrl+U. Export size scales to 100 / 75 / 50 / 33% of native resolution on the way out.

Upload with a history

Imgur, any S3-compatible bucket, or catbox.moe. Every upload is logged locally with its link, and providers that support deletion get a one-click delete right from the history.

Pin to screen

Float the capture as an always-on-top window: drag to move, scroll to resize, Esc to close. For holding a design over the thing you're building.

Tray and hotkeys

Lives in the tray with global hotkeys for every capture mode. All of them are rebindable in Settings - including the three that ship unbound.

Open existing images

PNG, JPEG, WebP or BMP from disk go straight into the same editor. Nothing about it needs the file to have come from a capture.

Settings that stick

Shortcuts, save folder, format and quality, export scale, theme, OCR and translation languages, upload credentials - all persisted across restarts.

cli

The same binary, without the window.

Non-interactive commands run headless - no window ever opens, and they work whether or not the app is already running. region, window and open forward to a running instance, or launch one.

$ slickshot region --edit # drag a region, then annotate it

CommandWhat it does
slickshot screenCapture the full virtual screen, headless.
slickshot monitor <index>Capture one monitor by index, headless.
slickshot window --title <text>Capture the first window whose title matches. Without the flag, opens the interactive picker.
slickshot regionInteractive region selection. Add --edit to land in the editor.
slickshot open <file>Open an existing image in the annotation editor.
slickshot ocr <file>Extract text and print it to stdout. --lang picks the recognition language, e.g. deu.
slickshot qr <file>Decode QR codes, one payload per line.
slickshot upload <file>Upload to the configured host and print the URL.
slickshot list-monitorsList monitor index, id and geometry.

Capture commands share -o, -c, --stdout, --edit and --delay. With none of them set, the capture is quick-saved to your configured folder and the path is printed. Full reference in docs/CLI.md.

platforms

Where it runs, honestly.

One codebase written to cross-platform APIs, and tested on all three desktop platforms. Wayland is the one real gap; the rest is a short list of quirks worth knowing before you install.

PlatformCaptureOCR engineStatus
Linux - X11 x11rb + xcap Tesseract Developed and used here
Linux - Wayland Not implemented - Seam ready for a portal backend
Windows 10 / 11 xcap Windows.Media.Ocr Verified on mixed-DPI dual 4K
macOS xcap Vision Core flows verified, Apple silicon

Wayland is not implemented. The ScreenCapturer trait is the seam a future xdg-desktop-portal backend plugs into; today only the X11 path exists.

Ctrl+S in the editor does nothing on Linux. WebKitGTK appears to swallow the accelerator before the page sees it. Quick save from the toolbar works; only that one shortcut, only on Linux.

Windows: PrintScreen may already be taken by Snipping Tool or OneDrive. The app tells you when the hotkey can't register - rebind it in Settings > Shortcuts.

macOS: a downloaded build says "is damaged and can't be opened." It isn't. Release builds aren't code-signed or notarized, and Gatekeeper won't accept an ad-hoc signature on an app carrying a browser's quarantine flag - so it reports damage instead of the usual unidentified-developer prompt. Right-click the app > Open, or clear the flag with xattr -cr.

install

Get SlickShot.

Every platform is bundled on the Releases page - CI builds them all from the same tag, so the versions never drift apart. Pick your format below.

Download the latest release

linux x86_64 & arm64 · windows x64 · apple silicon

Releases

Debian / Ubuntu

Grab the .deb for your architecture. It declares tesseract-ocr as a dependency, so OCR works the moment it's installed.

$ sudo apt install ./slickshot_*.deb

Fedora / RHEL

The .rpm is built in the same job as the .deb, and pulls in tesseract plus the English language pack.

$ sudo dnf install ./slickshot-*.rpm

AppImage

Self-contained, so it can't declare dependencies - install Tesseract yourself if you want OCR. The app detects it's missing and shows the right command for your distro.

$ chmod +x SlickShot_*.AppImage
$ ./SlickShot_*.AppImage

Windows

Run the installer - both an .msi and an .exe are published. OCR uses the engine already in Windows, so there's nothing else to set up.

Open the Releases page

macOS

Open the .dmg and drag SlickShot to Applications. OCR uses the built-in Vision framework, and macOS asks for Screen Recording on the first capture. If the first launch reports the app is damaged, it isn't - the build just isn't notarized. Right-click > Open, or:

$ xattr -cr /Applications/SlickShot.app
Open the Releases page

Or build it yourself

Needs Node with pnpm, a Rust toolchain, and your platform's Tauri prerequisites. Bundles land in src-tauri/target/release/bundle/.

$ git clone https://github.com/tuanpham-dev/slickshot
$ cd slickshot
$ pnpm install
$ pnpm tauri build
